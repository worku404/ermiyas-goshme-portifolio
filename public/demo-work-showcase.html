Architectural UI/UX Comparison & Decision Matrix

Pattern Primary Strengths Best Use Placement Hover & Motion UX Mobile Behavior
1. Infinite Kinetic Reel Recommended for Home Immediate cinematic life, zero scroll fatigue, panoramic crop makes renders look monumental. Home Page ("Selected Works" section) Continuous smooth gliding (42s loop). Pauses instantly on hover so user can read without chasing links. Fluid horizontal swipe track with touch momentum.
2. Viewport Walkthrough Recommended for Work Curatorial, museum-grade pacing. Displays blueprints, drawings, and competition awards alongside renders. /work Catalog Page (with optional Grid toggle) User controls pace with arrows, swipe, or natural scroll. Interactive progress bar (01/10). Stacked full-width hero cards with swipe gestures.
3. Curtain Accordion Striking architectural look; lets visitors compare all projects at a single glance without scrolling. Studio Exhibition / Desktop Showcase Expands to 65% width on hover with smooth spring cubic-bezier curves. Collapses into clean vertical accordion drawer cards.
